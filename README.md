# 🔥 FireBoard for Homey

> **The Complete Package.**

A complete Homey integration for FireBoard cloud-connected thermometers.

Monitor your FireBoard directly from Homey with live temperatures, dynamic probe names, battery monitoring, device health status and seamless Homey Flow integration.

---

## Features

### 🌡️ Monitoring

* Live probe temperatures
* Internal device temperature
* Battery level
* Dynamic probe names
* Automatic probe detection

### 📡 Connectivity

* Automatic online/offline detection
* Configurable polling interval
* Reliable cloud communication

### 🏠 Homey Integration

* Homey Flow Conditions
* Homey Flow Triggers
* Homey Insights
* Device availability

### 🌬️ FireBoard Drive

FireBoard Drive devices are automatically detected. Additional Drive functionality will be added in future releases.

---

## Supported Devices

* ✅ FireBoard 2
* ✅ FireBoard 2 Drive

Support for additional FireBoard devices is planned.

---

## Available Flow Cards

### Conditions

* Probe temperature is above…
* Probe temperature is below…

### Triggers

* Probe connected
* Probe disconnected

More Flow cards will be added over time.

---

## Installation

1. Install the FireBoard app.
2. Add your FireBoard device.
3. Sign in with your FireBoard Cloud account.
4. Select your device.
5. Enjoy!
